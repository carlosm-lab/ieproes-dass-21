# AGENTS.md — Panel DASS-21

- Proyecto: herramienta de tamizaje psicológico (DASS-21) para la Unidad de Psicopedagogía de IEPROES. Maneja datos sensibles de salud mental de estudiantes reales — trátalo con ese criterio.
- Todo el contenido visible para el usuario va en español.
- Nunca modifiques la lógica de cálculo de puntajes ni las reglas de severidad sin que se pida explícitamente.
- Sistema de diseño: glassmorphism, íconos reales (nunca emojis), mobile-first. Los estados de severidad crítica siempre llevan el máximo contraste y visibilidad.
- Antes de cualquier cambio grande de UI, propón el plan de diseño (colores, tipografía, componentes) para aprobación antes de tocar código.
